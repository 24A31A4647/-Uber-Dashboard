An interactive Uber Revenue & Earnings Dashboard developed using Microsoft Power BI to analyze financial performance and identify key revenue trends.

📊 Project Overview

This project focuses on transforming Uber revenue and earnings data into an interactive dashboard that provides clear, data-driven insights into financial performance.

🔍 Key Features
Analyzed overall revenue and earnings performance
Identified revenue trends and patterns
Created interactive KPI cards and visualizations
Used filters and interactive elements for data exploration
Presented complex data through an easy-to-understand dashboard
🛠️ Tools & Technologies
Power BI
Data Analysis
Data Visualization
DAX
Power Query
🎯 Objective

The objective of this project was to build an interactive Power BI dashboard that converts raw Uber revenue data into meaningful business insights and supports data-driven decision-making.

📌 Project Outcome

The dashboard provides an intuitive view of revenue and earnings performance, making it easier to identify trends, compare results, and understand overall financial performance.# -Uber-Dashboard
